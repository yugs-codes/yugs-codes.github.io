# Yugal Joshi — Personal Site

React + Vite personal profile for GitHub Pages.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Upload the contents of `dist/` to GitHub Pages, or connect the repository to GitHub Pages with the Vite build workflow.

## Notes

- Resume is in `public/resume.pdf`.
- Theme preference is persisted in localStorage.
- Replace or extend copy in `src/main.jsx` as research evolves.
